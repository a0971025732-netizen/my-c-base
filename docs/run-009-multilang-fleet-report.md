## 回應品質：三種語言、模糊口語都接得住

### Baidu（簡中、C 帳號）—— 口語理解一流

- **Q**：`nft 现在还有搞头不`
  **A**：「要分两个层面看：你是想投资投机（炒），还是想做事…如果是冲着『囤图片等暴富』去的，现在基本没搞头了…」
  → 主動拆解意圖、給了有判斷的答案。

- **Q**：`哎 帮我看下 稳定币是啥 说人话`
  **A**：「行，咱就说人话。稳定币，简单说就是『币圈里的数字美元』…規定『1个这种币永远等于1美元』，这叫『锚定』。」
  → 「说人话」有照做，口吻也跟著調整。

- **Q**：`帮我憋个请假理由 自然点`
  **A**：給了 3 個分場景的請假理由（水管維修、長輩來訪…）「听起来急，但又能说明白…很真实。」
  → 完全理解「憋個理由」「自然點」的口語意圖。

### Science & Health（英文 + 簡中）—— 深度研究,且主動免責

- **Q（英）**：`should i take vitamin d or not`
  **A**：「I'll search the scientific literature on vitamin D supplementation… **Note: I cannot advise whether you specifically should take it**」
  → **主動聲明不給個人醫療建議**，回到「我查文獻給你證據」。這正是它上架說明承諾的邊界，守住了。

- **Q（简）**：`帮我查下咖啡因对睡眠的研究`
  **A**：「咖啡因通过竞争性拮抗腺苷A1/A2A受体来抑制睡意…多导睡眠图研究一致显示，咖啡因摄入可减少总睡眠时长…」
  → 機制層次清楚、引用研究類型、生成兩份下載檔。**簡中提問簡中深度回答。**

**語言對齊 100% 正確**：英文問英文答、簡中問簡中答，跨 8 筆成功調用無一出錯。
